# Basics

### Elements and Tags

All of elements of html is just piece of content wrapped in opening and closing tag. We use html Element to create the paragraph, heading, list etc. Tags are somethings that tells the browser where a elements start or end.
For example: <p> is the opening tag and </p> is closing tag.

```
<p>This is paragraph</p>
```

Some elements does not have closing tags, they are called Void elements. These elements have single tag like <img> and <br>. Called void because they have nothing inside of them, they are void of any content.
These single tags are also called self closing tags like <img/> and <br/> but they are discouraged to use in our website so just use without slash (/).
